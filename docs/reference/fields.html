Save fields

Every field in the game's GameDataList (romfs GameData/GameDataList.Product.110.byml.zs). Each field is keyed by the MurmurHash3 (seed 0) of its name. Name is the game's own name, recovered by hashing strings found in the game's scripts, or in the game's memory while it runs (hover a name to see which); editor title comes from the onif save editor where known. Saved and area change come from each field's object in memory: whether the game keeps the field in the save slot (or another save file), and whether entering another area clears it (inferred, see FINDINGS §1). Progress only keeps the fields that are saved and kept across areas. Fields with 64-bit keys (Bool64bitKey) aren't listed.
